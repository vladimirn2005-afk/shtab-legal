Privacy Policy

Shtab Project Tools is a personal application used only by its owner for their own YouTube channels.

Data accessed

With the owner's consent the app accesses the owner's own YouTube channel data (videos, comments, analytics) through the YouTube Data and Analytics APIs.

Use and storage

Access tokens are stored only on the owner's own computer. The data is used solely to operate the owner's channels. It is not sold, shared with or transferred to third parties, and not used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through GitHub Issues of this repository.
